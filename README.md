# cadence-koi-ui

Pixel-art "koi pond" UI design for Cadence, a private music ledger and fetcher: style tile, animated 16-bit sprites, phone screens and fluid desktop/web pages.

- Read **[HANDOFF.md](HANDOFF.md)** first. It explains everything, including how to hand this to another Claude chat.
- Live canvas: https://claude.ai/artifact/6YfnW56BrZAwfcMyhB8yPh
- `tokens.css` holds the design tokens and pixel utilities; `design/` holds the source of every artboard and sprite.
